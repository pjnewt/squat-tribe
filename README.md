# Squat Tribe v1.1

This version embeds the five exercise illustrations directly inside `app.js`, so there is no `assets` folder to upload for the workout images.

## Upload to GitHub Pages
Upload these files to the root of your repository:

- index.html
- styles.css
- app.js
- sw.js
- manifest.json
- icon-192.png
- icon-512.png

Then enable GitHub Pages from the `main` branch root.

## Notes
- If an older version is already installed on your phone, remove it first or refresh after the new deploy.
- Because the service worker caches files, you may need to hard refresh once after deployment.
